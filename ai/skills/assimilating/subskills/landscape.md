# Landscape

For a pasted list of tools, a roundup post, or "compare to my setup": compare many sources at once, then assimilate the best few.

1. For each source, read its README or homepage only, and list its features in one line each.
2. Build one matrix: a row per feature, with the sources that have it and what dotfiles or glimmervoid has (a path, a spec or branch in flight, or none). Merge rows that name the same behavior under different brands.
3. Rank the rows the carbon unit lacks by value over cost, and pick the five sources that hold the top rows.
4. Run the skill's Steps 1 to 4 and the probes of Step 5 on each of those five, each feature credited to the source that does it best, holding the reply until all five are done.
5. Reply once: the matrix, then one numbered list in the skill's Output shape across all five, each item naming its source. Item 0 is full adoption of the top-ranked source; every other source's full adoption is a numbered item. Then stop for picks.
