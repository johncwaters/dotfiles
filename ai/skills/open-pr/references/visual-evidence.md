# Visual evidence

The repo's own screenshot or reviewer guide wins over this file, and so does any installed `open-pr-*` extension's evidence reference. This file carries what those guides leave to the agent's machine.

## Order, and why

1. **Own dev server port.** Check `lsof -iTCP:<port> -sTCP:LISTEN` first. Another worktree's server on the same port answers `localhost` and silently serves the old code, so a before/after grid shows no change.
2. **Before state from mainline, not memory.** Set uncommitted work aside in a WIP commit: on a dirty tree, first `git add -A` and `git commit -m "WIP set-aside"`, matching `/commit`. Sort the files with `git diff --no-renames --name-status origin/<mainline>...HEAD -- <files>`: `A` is added, `D` is deleted, the rest modified. Then `git restore --source=origin/<mainline> --worktree -- <modified> <deleted>` and delete the added files, capture, `git restore --source=HEAD --worktree -- <modified> <added>` and delete the deleted files again, then `git reset --soft HEAD~1` if you created the WIP set-aside commit. `--worktree` leaves the index untouched, and no per-file backup means two `index.tsx` cannot clobber each other. Wait ~30s for hot reload between states.
3. **Capture with `scripts/evidence.mjs`.** Run it in place as `node <skill-dir>/scripts/evidence.mjs <command> ...`; converge installs its locked dependencies. It drives the installed Google Chrome, so nothing downloads a browser and no `ffmpeg` is needed. On a Linux devbox without Chrome it falls back to Playwright's `chrome-headless-shell` (`npx playwright-core install --only-shell chromium` once) and links the system libraries it lacks into `~/.cache/evidence-chrome-libs`, because the Nix host has no `apt`.
   - `grid --url --selector --state before|after --area <slug> --out <dir>`: light and dark at 640px and 1440px, fresh context per shot, named `<state>-<area>-<mode>-<width>.png` so the later commands can pair them.
   - `gif --url --selector --target --out <file>.gif`: hover then click on `--target`, for anything that zooms, animates, or reacts. Writes three frame PNGs beside it; read them, since a GIF cannot be checked by opening the file.
   - `--local-storage '<json>'` (`{mode}` is substituted per shot) and `--dismiss '<selector>'` set the theme and clear banners; an extension's reference names the values for its sites.
4. **Console, both sides.** `grid` prints the console errors it saw; the PR claims "no new errors" only when the before and after sets match.
5. **Exercise beyond looking.** Click the control and read the clipboard, check the toast, check links. A still proves layout, not behavior. Wait for hydration before clicking; a click on static HTML does nothing and reads as a bug.
6. **Show before uploading.** `sheet --dir <dir>` writes `preview.html`; `open` it and get approval for the exact files, including the GIF and frames under Other files. Uploads are public and permanent.
7. **Upload per repo.** An extension or repo rule names the upload command. Otherwise, after Step 6 has created the PR (or in update mode), ask the carbon unit to drag the approved files into the PR description editor on GitHub and paste back what it inserts. Write each URL as a `![<stem>](<url>)` line, the stem being its file name without `.png`, into the upload output; the byte check below pairs each URL with its file. Verify each URL: `curl -sL -o /dev/null -w '%{http_code} %{size_download}'` must match the local byte count.
8. **Embed.** `markdown --uploaded <upload output> --area <slug> --heading <title>` prints the four-row before/after table the reviewer's guide asks for; it refuses when an upload is missing, so no cell is silently empty.
