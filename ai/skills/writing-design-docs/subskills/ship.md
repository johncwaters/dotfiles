# Ship

- **Draft beside the live doc.** A restructure goes in a new tab or a copy, keeping the original intact, so the author compares before anything is lost. When they prefer the draft, swap names and order; keep the old version as a tab until they delete it.
- **The author edits while you do.** Re-read the doc before every write. When a write is rejected because the doc changed, read again and rewrite only the parts they did not touch.
- **Preserve the author's removals.** A block, sentence, or highlight they deleted stays deleted, even when an edit fails because it is gone.
- **Edit in place.** Change the words that change, so comments, highlights, and embeds on the rest survive. Keep the same file and link.
- **Verify in the editor's own structure.** A plain-text or Markdown export can escape characters and drop images, which reads like broken links and a missing diagram that are not there. Confirm a defect in the editor's structured read before fixing it or reporting it.
- **Link the doc in the reply**, and say the link is unchanged after an edit.
